# Power BI Sales Dashboard
## Project Overview
Developed an interactive Power BI dashboard to analyze sales performance, revenue trends, and transaction behavior. The dashboard helps track business performance through KPI-driven insights and interactive visualizations.

## Tools & Technologies
* Power BI
* DAX
* Power Query
* Microsoft Excel

## Analysis Performed
* Analyzed monthly revenue trends (January–March)
* Compared sales channels (On Shop vs Online Orders)
* Tracked transaction amount totaling ₹9.86 Lakhs
* Evaluated sales performance using KPI metrics
* Generated business insights through interactive reports


## Key Insights
* Identified monthly revenue trends
* Compared sales channel performance
* Monitored transaction behavior for business decision-making
